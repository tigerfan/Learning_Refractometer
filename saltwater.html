01
先说清楚：公式本身没有问题
Lorenz–Lorentz 对水和 NaCl 溶液都成立。真正会出问题的，是它下面那句 "把各组分的贡献加起来"——这句话有一个隐藏前提。

四步换算出分子极化率

1
从麦克斯韦到介电常数
光在非磁性介质中 n² = ε_r。折射率就是"分子被电场拉弯了多少"的宏观平方根。
2
极化强度与数密度
单位体积偶极矩 P = N·α·E_loc，其中 N 是单位体积的极化单元数。 对电解质，这个"单元"是离子而不是分子。
3
Lorentz 局域场修正
扣掉分子自身产生的场，补上球形空腔壁的贡献：E_loc = E + P/(3ε₀)。 这一步让 n 变成 n²，也是它比 Gladstone–Dale 更准的根源。
4
联立得到可加和的形式
这一步是关键。从 P = Σ N_i α_i · E_loc 推出 (n²−1)/(n²+2) = Σ N_i α_i · 4π/3，看起来天然可加。

加和式的隐藏前提

Lorenz–Lorentz
n² − 1n² + 2 = 4π3 Σ Ni αi = ρ Σ wi ki
前提一 各组分的极化率 αi 互不影响。蔗糖分子之间隔着水，勉强成立； 离子周围有强电场，直接不成立。
前提二 球形空腔里的局域场是均匀的。离子表面的场强能到 10⁹ V/m 量级， 水分子在空腔里感受到的场根本不均匀。
后果 公式照样能算出一个数，只是那个数没有物理意义——它对应的是 "一群互不干扰的孤立离子"，而不是真实溶液。

02

03
失效的根源：离子把水锁住了
Na⁺ 表面电场约 10⁹ V/m，足以让周围的水分子放弃自由转动、按固定取向排队。 第一配位层里各有约 6 个水分子——它们不再是"水"，而是水合络合物的一部分。
Na⁺ 与 Cl⁻ 的第一水合层 · 取向示意

为什么取向会改变折射率

自由水 水分子随机翻滚，偶极方向各向同性。极化率的平均贡献稳定。
结合水 在离子场里被固定朝向，分子间距也被压缩到 0.28 nm 以下。 电子云被挤压变形，极化率随之改变。
净效果 同一份"水+盐"，在光频场下的总极化响应比"互不干扰地加起来"更大。 这就是表观 R 翻倍的原因。

电致伸缩：体积被压小了

离子电场把水拉紧，混合体积小于理想加和值。这个效应在电解质里比在糖溶液里强得多：

同样接近饱和：盐水 26 %（收缩 3.03 %），蔗糖 67 Bx（收缩 0.07 %）——差 46 倍—— 这就是"离子"和"中性分子"在堆积行为上的分野。

10
一页纸的公式链
前两步是"本该成立却没成立"，第三步是实际的解法。
① 电离
NaCl → Na⁺ + Cl⁻ ,  每 mol 盐给出 2 mol 离子
② 离子加和（失败）
Rion = 0.46 + 4.10 = 4.56 cm³/mol
代回 L–L 只给出实测的一半 → 该值对应孤立离子，不是溶液中的离子
③ 表观比折射度（反标定）
kapp = 0.1570 cm³/g ,  Rapp = 0.1570 × 58.443 = 9.18 cm³/mol
④ 混合求解
n² − 1n² + 2 = ρ [ w·kapp + (1−w)·kw ] , kw = 0.20606
⑤ 反解
n = √[1 + 2x1 − x] ,  x = ρ[w kapp + (1−w)kw]
⑥ 密度（外部输入）
ρ = f(w) 单调三次插值，20 °C 实测表
⑦ 温度修正（两通道）
n(T) = n(20) + [ (dn/dT)密度 + (dn/dT)结构 ] · (T − 20)
结构项 −2.0×10⁻⁵ (1 − 0.033w)，w 以 % 计
⑧ 反问题（仪器刻度）
w = f⁻¹(n) 二分法求根，无近似
⚠
注意这条链的诚实边界：第 ③ 步的 kapp 是从实测折射率反推的， 这意味着第 ⑤ 步算出来的 n 在某种意义上是在复述输入。 它的价值不在"预测"，而在于：用一个常数统一了 0–26 % 的全部数据， 说明这个体系的自由度只有 1 个。
✓
对比蔗糖页：那边 45 个原子 → Rm → n，全程零拟合； 这边 2 个离子 → 反标定 → n，有一个拟合参数。 两种做法的可信度差在哪，两页并排看最清楚。
