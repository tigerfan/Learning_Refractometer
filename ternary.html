01
加和式照旧，只多一项
前面两页分别验过蔗糖和 NaCl 的二元体系。把它们放进同一杯水里， Lorenz–Lorentz 的形式完全不变——溶质从 1 个变 2 个，就是多写一个 k。

三项加和

ws + wn + ww = 1，三个 k 都从前面两页沿用

这个式子在本页是可检验的：令 wn=0 退回蔗糖页，令 ws=0 退回盐水页。 两个端面都已经和实测对过（±0.0011 / ±0.0002），中间区域才是本页真正要讨论的部分。

可行域不是整个矩形

糖和盐会互相挤占水的容量。纯蔗糖能到 67 %，纯盐到 26 %，但两者共存时溶解度互相压低：

ws67.1 + wn26.4 ≤ 1
一阶线性近似，实际边界略向外凸（盐析效应的定量形式）
纯糖端wn=0 → ws 上限 67.1 %
纯盐端ws=0 → wn 上限 26.4 %
共存20 % 盐的卤水里，蔗糖最多只能再溶约 15 %——这就是腌渍时"加糖加不进去"的原因

密度：本页唯一的脆弱环节

三元密度没有现成的标准表。本页用"二元收缩加和"近似—— 把蔗糖–水、盐–水各自的体积收缩直接相加，忽略交叉项。端面因此严格锚定， 中间区域的不确定度估计在 0.3 % 量级。

夹角只有几度：这是方法的软肋

糖和盐都会同时推高 n 和 ρ，两个梯度方向很接近。在等比例坐标下看， 两族等值线的真实夹角只有 3–10°——之前那种"交叉很漂亮"的印象， 是坐标轴被拉长造成的错觉。

夹角小就是病态：n 差 1×10⁻⁴，配方就可能偏 0.1 % 以上。 这不是模型精度问题，是这套测量方案本身的信息量不够。

05
密度凭什么能区分糖和盐
同样一升溶液、同样重 1.118 kg，糖水和盐水的折射率能差 0.016。 这不是巧合，是两种溶质的"折射效率 / 密度效率"之比不同。

06
另一条路：用电导率代替密度
盐水导电，糖水不导电。所以电导率几乎直接给出盐度，再把盐度代回 n 的式子， 糖度就出来了——比测密度更便宜、更快。
20 °C 电导率 vs NaCl 质量分数mS/cm

两步反解

1
κ → wn
电导率对盐度近似分段线性，反解误差 <0.2 %。糖的存在会让 κ 轻微下降（黏度效应）， 20 % 糖时约低 3 %。
2
n + wn → ws
把已求出的 wn 代回三项加和，只剩 ws 一个未知数，直接解。
⚠
这条路只适用于可电离溶质。换成糖 + 甘油就没有电导可用， 只能回到 n + ρ。
07
现实中的糖盐水，读出来是什么样
折光仪只有一套 Brix 刻度。碰到含盐的样品，它会把盐也算成糖—— 这个"虚高"有多大，下面这张表说清楚。
典型配方 糖 ws 盐 wn nD ρ Brix 读数 虚高

"Brix 读数" = 把测到的 n 当成纯蔗糖溶液去查表得到的浓度；"虚高" = 读数 − 真实糖度。 单位均为 % w/w。

⚠
这就是工业上必须做"双参数"的原因。腌渍液按 Brix 判糖量，会把盐全算成糖—— 5 % 糖 + 10 % 盐读出来是 17.0 °Bx，误差 12.0 度，比仪器的 ±0.2 分辨率大了近 60 倍。

一页纸的公式链
从加和式到双参数求解。
① 三项加和
n² − 1n² + 2 = ρ [ wsks + wnkn + wwkw ]
② 三元密度（二元收缩加和）
1ρ = Σ wiρi − ΔV糖(ws) − ΔV盐(wn)
ΔV 从各自二元体系实测密度反算，交叉项未计入
③ 可行域
ws67.1 + wn26.4 ≤ 1
④ 单参数反解（欠定）
n = 1.3700 ⟹ 一条等值线，不是一点
⑤ 双参数求解
n(ws, wn) = n测 ,  ρ(ws, wn) = ρ测
两式联立 → 唯一解；数值上用归一化残差最小化求
⑥ 电导旁路（仅电解质）
κ → wn → n + wn → ws
⑦ 温度
n(T) = n(20) + (dn/dT)(T − 20)
dn/dT 由三元密度通道解析给出 + 结构通道修正
⚠
这页的诚实边界比前两页更大。三元密度是近似模型，中间区域没有实测校验， 双参数解的病态程度取决于配方位置。它适合讲清楚"为什么需要第二个测量"， 不适合直接拿去标定仪表。
✓
三页连起来看：蔗糖（零拟合、加和成立）→ 盐水（反标定、加和失效）→ 糖盐水（加和恢复、但自由度变成 2）。同一套 Lorenz–Lorentz， 三种完全不同的局面。
